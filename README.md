# Actual Sales vs Target Sales Dashboard | Excel

## Project Overview
The Actual Sales vs Target Sales Dashboard is an interactive Excel dashboard designed to analyze sales performance by comparing actual sales, target sales, and sales forecasts.

The project transforms raw sales data into meaningful business insights using Excel Pivot Tables, calculated metrics, and interactive dashboard visualizations. It helps monitor sales performance, identify trends, and evaluate business performance across different regions, brands, product categories, and sales channels.

## Dataset Description
The dataset contains **3,440 sales records** covering January 2023 to December 2024.

Key attributes include:
- Date, Year, and Month
- Region and Country
- Age Group
- Customer Satisfaction (CSAT) Score
- Product Returns
- Sales Type (Online and In Store)
- Customer Segment
- Brand Name
- Product Category
- Target Sales
- Sales Forecast
- Actual Sales

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Slicers
- Data Analysis
- Dashboard Visualization

## Dashboard Features

### 1. Sales Performance Analysis
- Comparison of Actual Sales vs Target Sales.
- Sales Forecast vs Actual Sales.
- Monthly sales performance trends.
- Sales performance by sales channel.

### 2. Regional & Brand Analysis
- Sales performance across different regions.
- Country-wise sales analysis.
- Brand-wise sales comparison.
- Segment-wise sales performance.

### 3. Customer & Product Analysis
- Customer satisfaction (CSAT) analysis.
- Product returns by category.
- Product returns by region.
- Monthly product return trends.

### 4. Interactive Dashboard
- Interactive filters for exploring sales data.
- Multiple dashboard views for performance analysis.
- Dynamic analysis across different business dimensions.

## Key Performance Indicators (KPIs)

| Metric | Value |
|---|---:|
| Total Target Sales | 52.01M |
| Total Sales Forecast | 61.80M |
| Total Actual Sales | 58.30M |
| Total Product Returns | 3.41M |
| Average CSAT Score | 4.20 |

**Key Insight:** Actual sales exceeded the overall sales target by approximately 12.09%, indicating positive sales performance during the analyzed period.
